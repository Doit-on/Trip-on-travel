# ติดตั้ง Apps Script (ใช้เวลาประมาณ 5–10 นาที)

ทำครั้งเดียว แล้วแอปจะได้:
- 📊 **Google Sheet** เก็บทริป ค่าใช้จ่าย โรงแรม และฐานข้อมูลสถานที่ (แก้ในชีตได้เลย)
- 📸 **Google Drive** เก็บรูปถ่ายแยกโฟลเดอร์ตามทริป
- 👨‍👩‍👧 **แชร์ทริปเดียวกันทั้งครอบครัว** แก้พร้อมกันได้ ระบบรวมข้อมูลให้
- ✨ **Gemini AI** ถามตอบ และจัดแผนรายวันให้ (คีย์อยู่ฝั่ง Google ไม่หลุดไปในเว็บ)

---

## 1. สร้างโปรเจกต์
1. เข้า <https://script.google.com> → **New project**
2. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เช่น `Tabi Note Backend`
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางเนื้อหาจากไฟล์ [`Code.gs`](Code.gs) ในโฟลเดอร์นี้
4. แก้ไฟล์ manifest:
   - ⚙️ **Project Settings** → ติ๊ก **Show "appsscript.json" manifest file in editor**
   - กลับมาที่ Editor เปิด `appsscript.json` แล้ววางเนื้อหาจากไฟล์ [`appsscript.json`](appsscript.json)
5. กด 💾 Save

## 2. รัน setup (สร้างชีต + โฟลเดอร์ให้อัตโนมัติ)
1. เลือกฟังก์ชัน **`setup`** จาก dropdown ด้านบน → กด **▶ Run**
2. Google จะขอสิทธิ์ → **Review permissions** → เลือกบัญชี
   - ถ้าเจอ "Google hasn't verified this app" → **Advanced** → **Go to Tabi Note Backend (unsafe)**
     (เป็นสคริปต์ที่เราสร้างเอง ใช้กับบัญชีเราเองเท่านั้น)
3. เปิด **Execution log** จะเห็น:
   ```
   APP_KEY  : xxxxxxxxxx   ← จดไว้ เอาไปใส่ในแอป
   Sheet    : https://docs.google.com/spreadsheets/...
   Photos   : https://drive.google.com/drive/folders/...
   ```

## 3. ใส่คีย์ Gemini (ไม่ใส่ก็ได้ แต่จะไม่มี AI)
1. ขอคีย์ฟรีที่ <https://aistudio.google.com/apikey> → **Create API key**
2. ใน Apps Script: ⚙️ **Project Settings** → **Script properties** → **Add script property**
   - Property: `GEMINI_API_KEY`  Value: *(คีย์ที่ได้)*
   - (ไม่บังคับ) `GEMINI_MODEL` = `gemini-2.5-flash` หรือรุ่นอื่นที่บัญชีใช้ได้
3. ทดสอบ: เลือกฟังก์ชัน **`testAI`** → Run → ดู log ว่า AI ตอบกลับไหม

## 4. Deploy เป็น Web App
1. **Deploy** → **New deployment** → ⚙️ เลือกประเภท **Web app**
2. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
3. **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> **แก้โค้ดทีหลัง?** ต้อง **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
> (URL เดิมใช้ต่อได้ ไม่ต้องเปลี่ยนในแอป)

## 5. เชื่อมในแอป
1. เปิดแอป → แท็บ **อื่นๆ** → **เชื่อม Google (Sheet · Drive · AI)**
2. ใส่ **Web App URL** + **APP_KEY** + **รหัสทริป** (ตั้งเองได้ เช่น `tokyo-fuji-2026`) + ชื่อเรา
3. กด **ทดสอบ** → **เชื่อมเลย**
4. (แนะนำ) กด **ส่งฐานข้อมูลสถานที่ขึ้น Sheet** ครั้งแรก เพื่อให้มีชีต Places ไว้แก้/เพิ่มเอง
5. ชวนครอบครัว: กด **ก๊อปลิงก์ชวนครอบครัว** แล้วส่งทาง LINE ใครเปิดลิงก์ก็เข้าทริปเดียวกันได้ทันที

## ชีตที่ได้
| ชีต | เก็บอะไร | แก้เองได้? |
|---|---|---|
| **Trips** | ข้อมูลทริปทั้งหมด (JSON) | ❌ ให้แอปจัดการ |
| **Expenses** | ค่าใช้จ่ายทุกรายการ + แปลงเป็นบาท/เยนตามเรทวันที่จ่าย | ดูอย่างเดียว (แอปเขียนทับ) |
| **Hotels** | โรงแรม + GPS | ดูอย่างเดียว |
| **Restaurants** | ร้านอาหาร + มื้อ + วัน + GPS + เมนูเด็ด | ดูอย่างเดียว |
| **Places** | ฐานข้อมูลสถานที่ | ✅ **เพิ่ม/แก้ได้เลย** |
| **Photos** | รายการรูปใน Drive | ดูอย่างเดียว |
| **Log** | ประวัติการใช้งาน / error | ดูอย่างเดียว |

### เพิ่มสถานที่ผ่านชีต Places (เช่น เอาข้อมูลจาก NotebookLM มาใส่)
- 1 แถว = 1 สถานที่ · `id` ใช้ภาษาอังกฤษ ห้ามซ้ำ เช่น `teamlab_planets`
- `dur` = เวลาที่ควรใช้ (นาที) · `gps` = `35.6491, 139.7898`
- `mapcode` = Mapcode สำหรับเนวิรถเช่าญี่ปุ่น
- `hi_th` / `miss_th` = จุดเด่น / ห้ามพลาด ถ้ามีหลายข้อให้คั่นด้วย `|`
- `art` = รูปการ์ด: `temple` `shrine` `street` `fuji` `lake` `water` `park` `city`
- แก้แล้วในแอปกด **ดึงสถานที่จาก Sheet** (หรือเปิดแอปใหม่ ระบบดึงให้เอง)

## ความเป็นส่วนตัว
- ข้อมูลทั้งหมดอยู่ใน Google Drive **ของเราเอง**
- ใครจะเรียกใช้สคริปต์ได้ต้องมี `APP_KEY` (อย่าโพสต์ลิงก์ชวนครอบครัวในที่สาธารณะ)
- รูปตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้แอปแสดงภาพได้ แต่ไม่มีใครค้นเจอถ้าไม่มีลิงก์
- เปลี่ยนคีย์ได้ทุกเมื่อ: แก้ `APP_KEY` ใน Script properties แล้วใส่ค่าใหม่ในแอป

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| `APP_KEY ไม่ถูกต้อง` | เช็กว่าก๊อปครบ ไม่มีช่องว่าง |
| `ยังไม่ได้รัน setup()` | ทำข้อ 2 |
| `รอนานเกินไป` | เช็ก URL ต้องลงท้าย `/exec` และ Who has access = **Anyone** |
| AI ตอบ `gemini_404` | ชื่อโมเดลไม่ถูกต้อง แก้ `GEMINI_MODEL` |
| AI ตอบ `gemini_429` | โควตาฟรีหมดชั่วคราว รอสักพัก |
| แก้โค้ดแล้วไม่เปลี่ยน | ต้อง Deploy **New version** (ข้อ 4) |
